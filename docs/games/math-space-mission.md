# Game Design Brief — Math Space Mission: Misi Antariksa

**Status:** Vertical slice tersedia  
**Rilis sasaran:** Game kelima setelah Math Castle  
**Fase awal:** A–D

## Janji permainan

Pemain menjadi kapten misi yang menjelajah planet. Jawaban matematika mengisi bahan bakar, menghindarkan roket dari asteroid, dan membuka rute menuju planet berikutnya.

## Vertical slice pertama

Math Space Mission membuktikan alur tiga planet:

1. Pemain memilih fase dan materi.
2. Peta menampilkan Bumi, Planet Merah, dan Planet Biru.
3. Jawaban benar mengisi energi dan menggerakkan roket di jalur planet.
4. Jawaban salah memicu feedback, mengurangi energi secara terbatas, dan mengulang konsep melalui mesin remedial.
5. Setelah semua navigasi dikuasai, pemain melihat laporan belajar dan progres misi.

Setiap planet adalah checkpoint naratif. Planet berikutnya terbuka berdasarkan penguasaan soal, bukan hanya kecepatan menjawab.

## Perluasan lintas fase

| Fase | Fantasi misi                     | Contoh materi                        |
| ---- | -------------------------------- | ------------------------------------ |
| A    | Mengirim satelit ke orbit        | Bilangan, tambah, kurang, pengukuran |
| B    | Mengisi bahan bakar antarbintang | Kali, bagi, pecahan, data            |
| C    | Membaca koordinat dan lintasan   | Desimal, persen, luas, volume        |
| D    | Memetakan sistem planet          | Persamaan, fungsi, geometri, data    |

Mode lanjutan dapat menambah pilihan rute, gravitasi, dan bahan bakar terbatas. Mode santai tetap menyediakan navigasi tanpa kondisi kalah keras.

## Kebutuhan mesin dan konten

Planet, checkpoint, biaya energi, dan feedback perlu didefinisikan sebagai data agar game dapat diperluas tanpa menyalin mesin sesi. Konten sebaiknya menghubungkan setiap tujuan belajar dengan peristiwa visual: roket berangkat, orbit berubah, atau gerbang planet terbuka.

## Kriteria keberhasilan desain

- Pemain memahami bahwa jawaban benar menggerakkan perjalanan.
- Tiga planet dan progres rute terlihat jelas pada layar sentuh.
- Kesalahan memberi penjelasan dan kesempatan memperbaiki strategi.
- Sesi selesai dalam 3–5 menit dan menghasilkan laporan penguasaan.
